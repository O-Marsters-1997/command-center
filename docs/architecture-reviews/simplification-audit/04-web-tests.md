- logstream_test SSE behaviour (follow until end, client disconnect).
- view/ unit tests of pure derivation: params round-trip, filterGroups, deriveBand cards, SpendCache, buildLogDetail. These are the right layer; keep, but table-drive.
- sourcecheck_test (guards the committed CSS actually scanning templates; 20 lines, cheap, unique).

Keep. faketp and fakegh binaries are essential: testscript needs a `tp`/`gh` on PATH; faketp delegating to real git is what makes cut/remove refusals genuine. No simpler substitute (a shell script would lose the squash-merge refusal fidelity). Keep ~224+96 lines, though faketp could lose a few lines (logging+fail env are both used by fail_cut/fail_*).
