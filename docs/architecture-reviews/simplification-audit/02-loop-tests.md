## 1. Essential coverage to keep
- RunOnce tick: observe -> persist -> dispose dead runs (by baseline commits, by origin tip when worktree gone, killed with partials) -> apply intents -> launch (cut via tp, spawn, record pgid); cut failure records cut_failed, never claims pgid.
- Launch gating: authorised hash must match composed prompt; max_agents cap shared by verbs and auto launches; spend_limit_5h pause + resume + never kills live run.
- Failed observe changes nothing and does not advance checking ticks (inv. 10).
- Push: policy refusal (denied paths) never pushes; create PR once, idempotent; adopt existing PR; failed push not auto-retried but retry-push bypasses; draft gate (draft while blocker open / verdict not green, ready exactly once, retry on failure).
- Refresh/restack: auto merge of advanced parent/main, never touches a worktree with a live run, conflict handling + retry-on-change only, generated-path conflict auto-resolve vs hand-written path left alone, verification failure not pushed, squash-merged parent restacked not merged back, never force-push a rewrite the app did not perform, retarget on parent merge.
- Verbs: re-run, follow-up, resolve, commit-resolution, remove-worktree safety (dirty/unpushed/diverged refused), close-PR, re-check parse.
- Merge events: recorded once with GitHub merge time; hand-churn metric.
- Import: closure/feature-conflict refusals, blocked_by repair on withdrawal, tracker fields refreshed but not branch/blocked_by; refusal does not halt tick.
- Store persistence that is not sqlc-trivial: withdraw keeps history, blocked_by JSON constraint, run disposition + request rows consistency, SetPassword transactional rollback, goose migrate idempotent.
